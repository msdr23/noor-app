# نُور — دليل النشر على Netlify

## تحديث: حاسبة مواريث موسّعة ⚖️
- تغطي الآن: الزوج/الزوجات (بما فيها تعدد الزوجات)، الأب، الأم، الجد لأب (كبديل كامل للأب)، الجدة، الأبناء والبنات، والإخوة/الأخوات (أشقاء / لأب / لأم).
- تطبّق قواعد **الحجب** (استبعاد وارث بوجود آخر)، **العَوْل** (تخفيض الأنصبة عند تجاوز مجموع الفروض للتركة)، و**الرَّدّ** (توزيع الباقي على أصحاب الفروض من غير الزوجين عند عدم وجود عصبة).
- **تم اختبارها فعليًا** على حالات فقهية معيارية معروفة (العُمَريّتان، عَوْل "زوج وأختان شقيقتان" الشهيرة، وحالة رَدّ) وطابقت النتائج المعروفة تمامًا.
- **لا تزال لا تغطي**: مسألة "الجد مع الإخوة" الخلافية بين المذاهب (نعامل الجد كبديل كامل للأب، وهذا رأي مبسّط)، أبناء/بنات الابن عند وفاة الابن، الأعمام والعصبات البعيدة، ذوي الأرحام، المفقود، الخنثى المشكل، ومسائل الأكدرية الدقيقة. هذا موضح بوضوح للمستخدم أسفل الحاسبة في الواجهة نفسها.

## ميزة جديدة: التفسير الميسر 📖
- تبويب جديد "التفسير الميسر" يعرض تفسير مجمع الملك فهد لطباعة المصحف الشريف آية بآية.
- يستخدم واجهة **alquran.cloud** المفتوحة والمجانية (edition: `ar.muyassar`) — لا يحتاج أي مفتاح API.
- الاتصال يتم مباشرة من متصفح المستخدم (client-side fetch)، فلا حاجة لدالة Netlify منفصلة لهذه الميزة.
- المصدر: مذكور بوضوح أسفل التبويب للامتثال لمتطلبات توثيق المصادر في المسابقة.

## ماذا تغيّر؟
- ✅ تمت إزالة مفتاح Gemini API نهائياً من كود المتصفح (index.html).
- ✅ الاتصال بـ Gemini الآن يمر عبر Netlify Function (`netlify/functions/ask-gemini.js`) تعمل على السيرفر.
- ✅ المفتاح يُخزَّن كمتغير بيئة (Environment Variable) لا يظهر لأي زائر للموقع.
- ✅ `SYSTEM_PROMPT` انتقل هو الآخر إلى السيرفر، فلا يمكن لأي شخص تعديله من أدوات المطوّر في المتصفح.

## خطوات النشر

### 1. احصل على مفتاح Gemini API
من https://aistudio.google.com/app/apikey

### 2. ارفع المشروع على GitHub
```bash
git init
git add .
git commit -m "نُور - نسخة آمنة"
git branch -M main
git remote add origin https://github.com/USERNAME/noor-app.git
git push -u origin main
```

### 3. اربط المشروع بـ Netlify
1. ادخل على https://app.netlify.com
2. اضغط **Add new site → Import an existing project**
3. اختر GitHub وحدد الريبو بتاعك
4. اترك إعدادات البناء كما هي (لا يوجد build command مطلوب، الملفات جاهزة)
5. اضغط **Deploy**

### 4. أضف مفتاح API (الخطوة الأهم!)
1. من لوحة تحكم الموقع في Netlify: **Site configuration → Environment variables**
2. اضغط **Add a variable**
3. الاسم: `GEMINI_API_KEY`
4. القيمة: المفتاح بتاعك
5. احفظ، وبعدين اعمل **Trigger deploy → Deploy site** عشان التغيير يتفعّل

### 5. اختبر
افتح رابط الموقع (مثال: `https://noor-app.netlify.app`) واسأل سؤالاً من تبويب المحادثة.

## استكشاف الأخطاء
- **"لم يتم ضبط مفتاح Gemini API على السيرفر"** → تأكد إنك ضفت `GEMINI_API_KEY` في Environment variables وعملت Redeploy.
- أي خطأ آخر: من لوحة Netlify اذهب إلى **Functions → ask-gemini → Logs** لرؤية تفاصيل الخطأ الفعلي القادم من Gemini.

## ملاحظات مهمة قبل التقديم للمسابقة
- نظام "تسجيل الدخول/حساب جديد" في الموقع تخزيني محلي بسيط (localStorage) لأغراض العرض فقط، وليس نظام مصادقة حقيقي وآمن — كلمات المرور غير مشفّرة بشكل صحيح (base64 فقط، وهذا **ليس تشفيراً**). إذا كانت المسابقة تتطلب نظام مستخدمين حقيقي، يُفضّل استخدام Netlify Identity أو خدمة مصادقة حقيقية بدلاً من هذا النظام.
- حاسبة المواريث حالياً مبسّطة وتغطي فقط: زوج/زوجة، أب، أم، أبناء/بنات. لا تغطي حالات الإخوة أو الأجداد أو الحجب المتعدد. يُفضّل ذكر هذا القيد بوضوح للمستخدم (موجود بالفعل في الواجهة) أو توسيع المنطق قبل التقديم لو الدقة الشرعية معيار تقييم مهم.
